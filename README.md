# Athena-AI
An intelligent AI-powered web application that explains any concept in three different levels — Child, Beginner, and Expert — making learning accessible for everyone. The platform also integrates YouTube videos directly within the site for enhanced visual understanding.

## Local setup for credentials

This project now loads sensitive keys from a local `config.js` file and keeps them out of git.

1. Copy `config.example.js` to `config.js`.
2. Fill `config.js` with your real keys.
3. Optionally keep the same values in `.env` for your own local reference.
4. Run the app on localhost.

Important: `config.js` and `.env` are ignored by git, so they will not be pushed to GitHub.
